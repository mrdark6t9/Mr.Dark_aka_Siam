## Wireshark Learning Resources

Comprehensive guides for learning Wireshark network analysis:

1. **[Wireshark Learning Guide](Wireshark_Learning_Guide.md)** - Complete introduction to Wireshark covering installation, basic concepts, interface overview, filters, protocol analysis, and troubleshooting tips.

2. **[Wireshark Quick Reference](Wireshark_Quick_Reference.md)** - Handy cheat sheet with essential display filters, capture filters, keyboard shortcuts, and common debugging scenarios.

3. **[Wireshark Practical Labs](Wireshark_Practical_Labs.md)** - Step-by-step hands-on labs for capturing and analyzing network traffic, debugging client-server applications, and performance analysis.

4. **[Wireshark for COMP1549 Coursework](Wireshark_For_COMP1549_Coursework.md)** - Specific guide for using Wireshark to debug and verify the Group Communication System (Task 1) requirements, including demonstration preparation.

### Quick Start

1. Install Wireshark from https://www.wireshark.org/download.html
2. Read the [Wireshark Learning Guide](Wireshark_Learning_Guide.md) for fundamentals
3. Practice with [Wireshark Practical Labs](Wireshark_Practical_Labs.md)
4. Use [Wireshark for COMP1549 Coursework](Wireshark_For_COMP1549_Coursework.md) to debug your project
5. Keep [Wireshark Quick Reference](Wireshark_Quick_Reference.md) handy while working

### Why Wireshark for This Coursework?

Wireshark helps you:
- Debug client-server communication issues
- Verify TCP/UDP protocol implementation
- Test coordinator ping mechanism
- Validate message delivery (private and broadcast)
- Measure network performance and latency
- Demonstrate fault tolerance scenarios
- Provide evidence during project demonstration
